# Plain language

Rewrite the person's text so that anyone can read it once and understand it, without changing what it says.

## Do this

1. Find the main point: what the reader must know or do. Put it first.
2. Rewrite the text:
   - one idea per sentence, most sentences under 20 words;
   - active voice, saying who does what;
   - everyday words in place of formal ones, using the list in references/plain-words.md;
   - "you" for the reader where the text speaks to them;
   - a list for steps, or for three or more items.
3. Keep every fact, number, date, name and condition. Keep a technical term the reader needs, and explain it in a few
   words the first time it appears.
4. Answer with the rewritten text, then one line saying what changed, such as "shorter sentences; the deadline is now
   at the top".

## Never

- Add information, or drop a condition, an exception or a number.
- Change the meaning to make a sentence shorter.
