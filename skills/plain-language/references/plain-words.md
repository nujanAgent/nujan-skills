# Plain words

Use the word on the right, unless the formal word is the precise term the reader needs.

| Instead of | Write |
| --- | --- |
| accordingly | so |
| additional | more, extra |
| approximately | about |
| assist | help |
| commence | start, begin |
| consequently | so |
| demonstrate | show |
| endeavour | try |
| facilitate | help, make easier |
| in order to | to |
| in the event that | if |
| in relation to | about |
| notwithstanding | despite, even though |
| obtain | get |
| prior to | before |
| purchase | buy |
| regarding | about |
| require | need |
| subsequently | later, then |
| sufficient | enough |
| terminate | end |
| utilise | use |
| with regard to | about |
