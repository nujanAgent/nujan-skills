# Code of conduct

This project follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

To raise a concern about conduct in this project, open an issue in this repository. Content that breaks GitHub's own
rules can also be reported to GitHub, as described in
[Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
